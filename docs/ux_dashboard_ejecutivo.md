# UX dashboard ejecutivo

## Direccion visual

Interfaz de gestion sobria para gerencia: navegacion lateral fija, area principal densa pero respirable, tarjetas de KPI compactas, graficos simples y tablas de accion rapida. La paleta evita depender de un solo azul: combina fondo frio claro, sidebar petroleo, acentos teal, azul operativo y alertas ambar/rojo.

## Pantallas

- Login gerencial con contexto de solo lectura.
- Dashboard principal con filtros de periodo, busqueda de deudores y refresco.
- KPIs del primer entregable: facturacion, cobranzas, deuda, consumo, conexiones, lecturas recientes y pendientes.
- Panel de evolucion mensual.
- Top deudores y calidad de datos.

## Reglas de UX

- Primero mostrar estado ejecutivo, no configuracion tecnica.
- Marcar claramente si la fuente es demo local o VPS MySQL.
- Usar tablas/listas para informacion gerencial, no tarjetas decorativas repetidas.
- Mantener botones con iconos para acciones instrumentales.
- Evitar mapas en esta primera pantalla hasta contar con coordenadas confiables.
